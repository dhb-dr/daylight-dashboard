# Daylight 个人仪表盘

纯静态中文个人学习仪表盘，使用原生 HTML、CSS、JavaScript，无需构建或安装依赖。

## 启用公开网址

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. 选择 `main` 分支和 `/(root)` 目录，点击 **Save**。
4. 发布完成后，网址为：<https://dhb-dr.github.io/daylight-dashboard/>

## 数据和功能

- 日期、星期、实时时钟；待办新增、完成、删除。
- 每日学习目标和本周学习记录；点击柱状图可编辑当天累计分钟数。
- 深浅主题切换。
- 待办、学习记录与主题设置仅保存在访问者自己的浏览器 localStorage 中，不会上传或在设备间同步。
- 天气模块明确显示未连接实时天气服务。
